# Controle de Gastos

App web (PWA) para acompanhar cartão de crédito e conta (Pix) a partir dos arquivos OFX/CSV do banco.

- Abra no iPhone pelo Safari e use **Compartilhar → Adicionar à Tela de Início**.
- Depois da primeira abertura, funciona sem internet.
- **Nenhum dado fica neste repositório**: extratos, regras e lançamentos ficam só no aparelho (armazenamento do navegador). Use "Exportar dados" para fazer backup.
